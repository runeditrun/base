# Local acceptance

To bring records in, sign in as the owner and open:

```text
/app/import
```

Export people from another default-seed installation, upload that unchanged
JSON, review and approve the plan, apply, reconcile the native people and undo.
The built Worker journey runs the adoption guide's public HTTP conformance on
a freshly claimed default seed. The same door carries Business grants when the
owner opts in; disabling grants does not disable owner imports or Undo.

Frozen installation, real build and migrations, one-click development
sign-in, native session admission, private-response rules, HMR and confirmed
reset are checked with the actual shared modules and local Worker runtime.
Installation backup/restore uses the separate shared portability archive
mechanism with integrity checks and erasure fences. Provider delivery and hosted acceptance
are separate; local verification makes no such claim.
